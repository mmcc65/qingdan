# 清单 HarmonyOS 原生版

这是面向 HarmonyOS NEXT / HarmonyOS 5 及以上设备的原生客户端工程。它通过 ArkWeb 复用清单的完整界面与业务逻辑，并使用 Form Kit 提供真正的鸿蒙桌面服务卡片，不依赖卓易通的 Android 小组件兼容能力。

## 已实现

- 手机和平板设备类型，当前兼容目标为 HarmonyOS 6.0.0(20) 及以上。
- 原生动态服务卡片，包含待办、重复、项目、日程、随笔五个页签。
- 卡片列表可纵向滑动，不再只显示前五项。
- 卡片内可以完成待办、完成一次重复任务、结束项目或完成日程。
- 随笔显示序号、置顶状态和备注提示，并按置顶组及手动顺序排列。
- 网页与原生 Preferences 双向同步；卡片改动会在下次打开应用时合入页面并继续执行既有云同步。

## 同步共享页面资源

在仓库根目录执行：

```powershell
node tools/sync-harmony-web.mjs
```

每次修改 `apps/web` 后、构建 HAP 前都应运行一次。

## 构建要求

- DevEco Studio 6.0.2 Release 或同版本 Command Line Tools
- HarmonyOS SDK 6.0.2(22)
- 已登录的华为开发者账号，用于自动签名和真机调试

使用 DevEco Studio 打开本目录，等待工程同步后选择连接设备，启用自动签名并运行 `entry`。发布包需要创建 Release 签名后生成，不能把未签名 HAP 直接安装到真机。

## 添加桌面卡片

安装并至少打开一次清单后，在桌面双指捏合进入编辑，选择“服务卡片”，找到“清单”，选择合适尺寸后添加。卡片支持 `2×4`、`4×4` 和 `6×4`。

如果列表为空，请先打开应用一次，使网页数据写入鸿蒙本机存储；已配置 Supabase 的设备会继续沿用应用内的云同步设置。
