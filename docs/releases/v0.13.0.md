# 清单 v0.13.0

日程新增「日筏」：选择某一天，写下那一天的整体计划、重点和备注，方便提前安排明天、后天。

- 入口与日程筛选并列，顺序为「总览 → 日筏 → 行程 → 已完成 → 已取消」。
- 每天一篇，支持多行文字（最多 5000 字）、编辑、确认删除、全局搜索。
- 日期切换显示对应内容；手机浮动添加按钮随模块切换为「写日筏」。
- 内容存于本机，并纳入现有整份状态同步机制；兼容旧数据。
- 更新中英文项目介绍及桌面、手机截图，同步 HarmonyOS Web 资源。

验证：12 项核心测试、完整桌面/手机 UI 检查、HarmonyOS 项目检查，以及 Windows 和 Android 安装包构建。

## 下载与更新

- Windows：下载 `Qingdan-desktop-release.zip` 解压使用，或在应用设置中检查更新。
- Android / 兼容 Android 的 HarmonyOS：下载签名的 `Qingdan-mobile-release.apk`，或在应用设置中检查更新。
- 更新附件包含 `desktop-latest.json`、`latest.json` 与 SHA-256 校验信息。
