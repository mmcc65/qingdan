# 变更记录

本项目从公开预览版开始遵循语义化版本号。

## [0.5.0] - 2026-08-14

- Windows 与 Android/HarmonyOS 应用内更新通道
- Windows 桌面稳定快捷方式创建脚本
- 多级子项目与项目内部任务

- 独立于数据同步服务的官方更新清单配置

- 统一 Web、Windows 和手机版本号

- 更新公开发布说明和自托管步骤
